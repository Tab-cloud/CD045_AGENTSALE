## 浏览器实际操作

在本机应用 `http://127.0.0.1:3045` 操作，不是静态 HTML 样稿：

1. 录入 `QA-20260906`，候选商品由 3 增至 4，来源由 3 增至 4；商品档案可检索访问。
2. 采购 ¥44.64、假设汇率 7.2、净收入 $29.90，运费为空时利润显示「—」，提示补充国际运费。
3. 补齐物流 $5.60、平台 $1.50、售后 $1.00、内容 $0.60、获客 $6.00，页面得到贡献利润 $9.00 / 30.1%，采购折算 $6.20，获客盈亏平衡点 $15.00。
4. 保存「验收用包装资料」，保留未核实状态，商品版本更新；随后创建模板任务。
5. 内容页生成模板，人工修改并保存脚本，再通过审阅；任务页显示完成且明确没有渲染或发布视频。
6. 停止应用、重新启动并重新加载页面，商品、脚本 v3 和已审阅状态仍存在。
7. 内容选择器与草稿一致；切换到没有草稿的商品显示空状态。
8. 将验收样品净收入改为 $30.90，旧稿显示「资料已更新」，通过审阅按钮禁用。重新核对并保存后回到待审阅。
9. 检查 1440px 桌面浅色/深色界面；390px 手机概览、内容页和店铺页页面宽度未溢出（innerWidth 390，document scrollWidth 375）。最终概览页浏览器错误日志为空，临时视口已恢复。
10. 店铺结账按钮只打开说明弹窗，Escape 可关闭，没有进入支付或收集个人信息。

暂停/继续和文件队列恢复的强制时序通过数据库测试验证；未声称在浏览器中成功抢在 1.5 秒消费前暂停任务。手机检查不等于完整无障碍认证或真实移动结账验收。

## 本机兼容处理

- E 盘 exFAT 不支持默认依赖软链接；使用 pnpm 11 YAML 中的 hoisted/copy 配置和源码路径映射。
- exFAT 上 PGlite 文件初始化实测失败；C 盘 NTFS 写入、关闭和重开成功。运行数据独立放在 `%LOCALAPPDATA%/AgentSale/CD045_AgentSale-cd0898b7/pglite`。
- Next 构建遇到 exFAT readlink 错误，根目录启动工具在确认目标不是软链接后规范化错误码。没有修改依赖包源码或关闭业务校验。说明及官方问题链接见 [工程范围](../plan/08-first-implementation.md)。
- 首次浏览器写入发现 Next 内部 URL 与 HTTP Host 不同；已改为先验证 Host 再比较 Origin，并新增回归测试，浏览器保存复验成功。
- 旧安装缓存的删除被执行策略拦截，保留在项目 `.local/install-recovery`；该目录被忽略，不属于业务数据或源码交付。当前应用与依赖安装不受影响。

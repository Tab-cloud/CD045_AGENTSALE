# 市场决策层验收报告

版本：v0.5 / 2026-09-06。

本次交付为运营工作台新增“市场决策”页面，打通平台数据快照、持久化时间序列、确定性评分、置信度、建议和评分依据。

## 已验收行为

- 支持 TikTok Shop、Temu、Amazon、Shopify 和其他平台；
- 保存商品、平台、国家、日期、来源和九类市场/履约指标；
- 未填写指标保持未知并降低覆盖率，不按零分处理；
- 同一统计组合的两期数据计算销量与浏览趋势；
- 五个评分维度展示分数、覆盖率及具体计算依据；
- 没有确认供货证据、使用示例商品或缺关键数据时不会建议测试；
- 公开观察即使分数较高也只进入继续调研；
- 数据表受工作区 RLS 和运营角色 API 权限保护。

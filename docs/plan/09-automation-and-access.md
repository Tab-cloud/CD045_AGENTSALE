# 自动化与管理员权责实现

版本：v0.2 / 2026-09-06。本文件描述当前已实现范围，覆盖首批文档中“无 AI 调用、无视频、无登录”的历史状态。完整商业 MVP 仍按总纲推进。

## 产品决定

用户确认：平台承担分销，供货方必须支持发货；选品与国家应由 AI 基于可采购的供应商判断，而非要求运营先定商品或国家。本机管理控制台负责模型与连接器配置，运营门户负责业务流程。

发现流程无需预选市场。默认搜索中国大陆单件代发供应商，最多取 5 个来源；可附加品类限制或已知网址。模型必须给出来源中存在的大陆、代发、目的国配送原文引用。系统只核对引用存在与结构完整，不能把网页声明等同于工厂真实性、实物质量或履约承诺。符合引用要求时自动建立“来源声称，待独立核验”的商品，采购和运费保持未知。

v0.7 已增加独立市场决策层与授权渠道连接器：可自动同步 TikTok Shop 商品表现和 TikTok Shop、Temu 店铺订单，也可保存授权导出或人工核对的销量、浏览、互动、评价、竞争、价格、交付和退款快照，并与成本及供货证据形成确定性评分。税费、样品与利润实测仍需独立核验，不能把公开观察数据当作已验证商机。

## 可执行流程

| 入口 | 步骤 | 结果 |
|---|---|---|
| 自动发现供应商与市场 | 搜索或接收来源 → 正文采集 → AI 供货/市场研究 → 文件整理 | 候选商品、引用、缺证项、询价草稿；进入审阅 |
| 商品准备 | 来源采集 → 确定性成本测算 → AI 供货研究 → AI 营销文案 → 图片视频 → 文件整理 | 可编辑分镜、MP4、SRT、推广正文、研究与素材清单 |
| 已有素材转视频 | 使用人工三段文字与已授权图片 → 编码 → 文件整理 | 真实 MP4，不依赖模型；界面标明文案并非 AI 生成 |

来源采集支持公开 HTML，不绕过登录、验证码或站点访问规则；动态页面、授权 B2B 平台、私有供应商报价接口需要后续专用连接器。无搜索密钥时可提供来源网址；无可用模型时停在需要模型的步骤，已完成数据保留。

视频是 720 × 1280、15 秒、三段各 5 秒的图片分镜短片，H.264、24fps、无配音，文字嵌入且带草稿标记。图片需人工上传并记录权利来源，不自动抓取商品图。文件输出后运行媒体元数据检查与整段解码验证。文案修订保留来源引用，撤销原审阅，重新渲染和打包。

## 管理与运营入口

| 操作 | 本机管理控制台 | 运营门户 |
|---|---|---|
| 模型端点、密钥、搜索密钥、预算配置和验证 | 允许 | 服务端拒绝 |
| 建立/停用账号 | 当前不提供 | 当前不提供 |
| 商品/证据、流程控制、上传素材、编辑和内部审阅 | 不提供 | 允许 |
| 获取密钥明文 | API 不提供 | API 不提供 |
| 外发消息、发布、交易 | 已验证连接器与管理员启用策略 | 连接器状态、事件幂等、外部响应与结果对账 |

v1.0 根据当前产品阶段移除了两个入口的登录、退出和账号维护。业务与管理 API 均限制在本机地址，写操作校验 Origin，管理代理只转发管理接口；该模式只用于本机单用户开发。原认证模块保留为后续账户体系的内部基础，但不再暴露登录路由。

Windows 配置使用 DPAPI CurrentUser 加密，密钥经标准输入交给系统保护程序，不作为进程参数或日志。其他系统使用 0600 文件密钥与 AES-GCM，但尚未做跨平台实机验收。端点变更清除旧模型密钥，管理员可主动清除两个服务密钥。配置写入串行，旧连接验证不能覆盖新版本配置。

当前是本机单工作区的入口隔离；尚无部门级资源权限、SSO/MFA、密码找回、多人公网部署及操作系统级隔离。

## 技术结构

Next.js 路由负责本机来源、输入验证与工作区准入；`packages/automation` 负责状态机、来源、模型、媒体和凭据。PGlite + Drizzle 保存流程 JSON、素材、调用预留账本，沿用非所有者运行角色与工作区 RLS。外部调用不占用数据库事务。

后台服务每 1.5 秒领取一个步骤，租约、行锁、版本检查保证当前单进程内受控推进。输入及商品版本冻结；每次领取和最终审阅校验商品版本，旧商品产物不能继续通过。暂停阻止下一步，已发出的请求保留返回结果。重启会释放中断租约、阻塞步骤并要求显式继续；不会自动重发结果未知的付费请求。

模型通过真实 HTTP Chat Completions 接口调用，支持 JSON Schema 或 JSON 模式以及两个常见输出上限参数。服务端重新验证结构与引用。网页文本作为不可信数据，模型无法调用外发工具或获取服务密钥。连接必须实际返回符合验证结构的结果，保存不代表就绪；验证 24 小时后需重验。搜索使用 Brave Search 的官方 Web Search API。

来源网络访问拒绝环回、内网、元数据、非 HTTP(S) 和非标准公开端口；解析 DNS 后检查并固定连接地址，重定向重新校验地址和域名范围，限制大小和超时。本机模型只有显式开启后允许 localhost/127.0.0.1/::1。

调用前数据库事务原子预留管理员单次、每日与流程总额度，并发请求不能绕过总额。额度是配置的保守成本上限，成功记录 token 用量，异常留为未知；不是准确费用结算或供应商侧硬封顶。真实计费仍取决于外部账号配置。

## 后续接入与验收

1. 管理员配置真实模型与搜索，实际验证模型结构化输出，再让发现流程自行研究首批货源；逐条复核来源、代发条件、样品与报价。
2. 接供应商授权数据/素材与发货能力，建立询价收发和回复归档，授权范围内执行沟通。
3. 接一个海外渠道的正式发布接口和状态回读，再接电商结账、支付回调、订单履约、物流和分销结算。
4. 实施生产 PostgreSQL、独立工作器、正式身份系统、外部动作幂等、备份恢复和跨进程压力验证。当前本地工作器不作为这些生产能力的完成证据。

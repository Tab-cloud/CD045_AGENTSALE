# 自主经营 Agent 与执行层

版本：v0.6 / 2026-09-06。

AgentSale 的主要产品形态是持续运行的自动化电商 Agent。用户通过自然语言或斜杠命令设置经营目标、预算和执行周期；后台运行时负责调度专业子流程、读取结果、决定下一动作并持续保存审计记录。商品、市场决策和内容页面是可观察的工具界面，不是完成工作的必经步骤。

## 分层结构

| 层级 | 职责 | 当前实现 |
|---|---|---|
| 对话控制层 | 理解自然语言及 `/命令`，维护目标、预算、周期和运行状态 | 已实现 |
| 研究 Agent | 搜索中国大陆供应商、抓取公开来源、验证大陆供货/代发/目标国证据 | 已实现；依赖搜索配置或已有链接 |
| 决策 Agent | 聚合平台快照、成本、供货证据，计算趋势、五维评分和置信度 | 已实现 |
| 内容 Agent | 生成商品详情、推广文案、海报、配音和视频 | 已实现；需要模型及授权素材 |
| 执行 Agent | 根据决策启动子流程、自动完成内部审阅、处理恢复和阻塞 | 已实现 |
| 渠道 Agent | 发布到海外平台、回读曝光点击和转化 | 接口待接入 |
| 订单 Agent | 下单、采购通知、物流、客服、售后和佣金 | 接口待接入 |

## Agent 命令

- `/goal <目标>`：设置持续经营目标；
- `/budget <美元>`：设置每个自动周期的模型与搜索预留上限；
- `/interval <分钟>`：设置 1–1440 分钟的执行周期；
- `/start`、`/pause`、`/run`：启动、暂停或立即执行一个周期；
- `/discover [方向]`：直接调用研究 Agent；
- `/content <SKU>`：直接调用内容 Agent；
- `/status`、`/config`、`/help`：查看状态、配置入口和命令。

确定性命令和常见中文意图优先在本机解析。无法确定的自然语言才交给已验证的模型，并强制输出允许动作的结构化 JSON。模型只能选择白名单动作，不能直接访问密钥、数据库或外发工具。

## 自动周期

每次周期依次检查：

1. 是否存在待完成的流程；存在时继续等待执行结果。
2. 是否存在待内部审阅的内容；自主模式下自动完成内部审阅并记录执行人。
3. 是否有达到“小额测试”门槛的商品；有授权素材时自动启动内容生产。
4. 没有决策数据时启动供应商发现，或等待市场数据连接器。
5. 缺少搜索、素材、市场数据、发布或订单连接器时进入明确的 blocked 状态，不伪造成功。

Agent 状态、所有者、消息、运行记录和下一周期时间持久化。blocked 状态仍会按周期重新检查连接器和数据，条件恢复后无需人工再次启动；显式 `/pause` 才停止周期。服务重启后读取原状态；付费请求沿用预算预留、幂等和结果未知保护，不盲目重复提交。

## 无人干预目标

目标运行形态允许用户完成一次服务授权和经营政策配置后，由 Agent 持续运行。实现这一目标还需要市场数据、商品素材、海外发布、店铺订单、支付、物流和客户消息的正式连接器。当前运行时已经能自动决定和调度已接通能力，并把未接通能力显示为阻塞原因。

外部发布、采购、退款和客户消息将按照管理员设置的授权范围、金额上限和停止条件执行。接入前不会用浏览器绕过平台审核，也不会用演练回执冒充真实经营动作。

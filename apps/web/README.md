# Web 端

集中存放现有 Web 项目与后续 Web 服务。

| 目录 | 当前职责 | 目标职责 |
|---|---|---|
| `console/` | 会员页面、身份/订阅与 AI/API 服务接口；旧业务 API 仅供迁移验证 | 服务端统一接口 |
| `admin-console/` | 静态管理页面：模型、搜索、媒体、支付和账号配置 | 管理员入口 |
| `packages/` | 服务端数据与服务模块；部分旧自动化代码待迁移 | 服务端内部模块 |
| `scripts/`、`tests/` | 启动、验收工具和 Web 测试 | 服务端构建与回归验证 |

Web 端只承载账号、会员、管理员配置和 AI/API 服务接口。研究、任务编排、内容制作及成果管理在桌面端实现。旧业务 API 仅在本机迁移验证模式开放，公网部署返回 404；旧代码尚未清退。

计划中的会员中心与桌面 API 公网地址为 `https://lingfeng.zailink.space`，管理员入口为 `https://admin.lingfeng.zailink.space`。部署时分别设置 `LINGFENG_PUBLIC_URL` 与 `LINGFENG_ADMIN_URL`；这只是目标域名记录，不表示 DNS、HTTPS 或服务已部署。

公网部署前请按 [Web 服务部署前审核](../../docs/reports/2026-09-28-web-predeployment-review.md) 逐项验收。现阶段可部署隔离预发布环境联调；真实收费和公开注册仍须完成服务商配置、资质审核与端到端验收。

从仓库根目录执行 `pnpm build` 后用 `pnpm start` 启动。3045 是唯一的 Next 服务进程，提供会员页面和接口；3047 由轻量静态服务器提供管理员页面，并只代理管理接口到 3045。两者由同一个启动器管理。`pnpm dev` 会先构建静态管理页面，修改管理页面后需重启开发进程。请通过根目录启动入口运行，以沿用原有数据目录。

Web 专用业务逻辑位于 `packages/`；根目录 `../../packages/` 保留 Web 构建所需的视觉样式和技能目录。历史研究、配置与素材仍使用原数据位置；此次整理只移动源码、脚本和测试。

## 账号、短信和微信登录

管理员页面新增“用户管理”和“订阅账单”。用户管理可查询账号、手机号、微信绑定及会员状态；账单页按订单号、用户、手机号和支付状态检索现有会员订单。账单仅代表订阅订单，不生成税务发票。

管理员需在“登录与短信 → 阿里云短信”配置阿里云短信的 RAM AccessKey ID/Secret、已审核短信签名和验证码模板 CODE（模板变量为 `{code}`），启用后公网才允许手机号验证码注册。密钥加密保存在服务器数据目录，管理页面只回显“已填写”。旧的用户名注册只在本机演练模式开放；已注册用户仍可使用原账号和密码登录。

微信登录使用**微信开放平台网站应用**的 App ID 和 App Secret，在“登录与短信”页面配置并启用。开放平台的“授权回调域”填写 `lingfeng.zailink.space`，实际回调入口为 `https://lingfeng.zailink.space/api/v1/wechat/callback`。用户先登录原账号，在会员中心绑定微信后才能使用微信快捷登录；未绑定的微信不会自动创建新账号或迁移会员权益。微信登录配置与微信支付商户配置相互独立。

上线时需实测阿里云验证码发送与微信授权回调；本地自动化测试使用模拟短信发送，无法代替真实服务商凭据和网站应用审核。
